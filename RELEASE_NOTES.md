# Release Notes – Version 1.0.2

citation metadata, reproducibility, and technical organization.

- Added a Creative Commons Attribution 4.0 International license.

- Rewritten and simplified `README.md`.
- Improved repository documentation.
- Updated repository metadata for version 1.0.2.

## Fixed

- Improved notebook portability.
- Standardized text file line endings.
- General repository housekeeping.

The published CSV datasets have **not** been modified in this maintenance release.
