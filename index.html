About the data

The accumulated map loads the repository CSV files directly in the browser: v_sites_geo.csv, v_events_dst.csv, v_damage_dst_unified.csv, and v_env_effects_dst_unified.csv. Effect records are joined to sites through Sites_GlobalID → GlobalID and to earthquakes through Event_Id → Id.

Confidence filter

The radio buttons under Layers are generated automatically from all unique values found in the Rel field of both effect datasets. All displays every record. A selected Confidence value filters both thematic layers.

Visual encoding

Earthquake Damage: each circle represents one site. Circle size represents the number of visible damage occurrences at that site after the Confidence filter is applied.

Environmental Effects: each square represents one site. Square size represents the number of visible environmental-effect occurrences after filtering. Square colors represent the visible Env_Eff types; a segmented square indicates several effect types at the same site.

Popups

Each popup begins with the site name and coordinates. Records are organized by linked earthquake. Damage popups display Confidence, damage and casualty classes, intensity values, building and population totals, casualties, injuries, and description. Environmental popups display Confidence, effect code and name, category, description, and ESI value.

Views

Accumulated damage contains the current map and controls. Damage/Env Effect by Earthquake(s) is an empty placeholder for a future earthquake-selection view.

Scope

The symbols represent documented historical effects at reported sites. They do not necessarily represent earthquake epicentres or instrumental ground-motion measurements.
