About the data

The accumulated map loads the repository CSV files directly in the browser: v_sites_geo.csv, v_events_dst.csv, v_damage_dst_unified.csv, and v_env_effects_dst_unified.csv. Effect records are joined to sites through Sites_GlobalID → GlobalID and to earthquakes through Event_Id → Id.

Confidence filter

The shared Confidence filter uses a fixed ordered scale for both thematic layers: Poor, Doubtful, Unknown, Moderate, High, and Very High. All displays every record. The displayed value Unknown also supports legacy records stored as U.

Visual encoding

Earthquake Damage: each circle represents one site. Circle size represents the number of visible damage occurrences at that site after the Confidence filter is applied.

Environmental Effects: each square represents one site. Square size represents the number of visible environmental-effect occurrences after filtering. Square colors represent the visible Env_Eff types; a segmented square indicates several effect types at the same site. The legend lists environmental effect types by color and does not repeat occurrence-size classes.

Popups and tooltips

Each popup begins with the site name and coordinates. Linked earthquakes are displayed sequentially in a vertically scrollable list, with only the earthquake date shown as each section heading. The Confidence field is visually emphasized. Damage popups display damage and casualty classes, intensity values, building and population totals, casualties, injuries, description, references, and links. Damage tooltips in both maps also include the new References and Links fields. Environmental popups display effect code and name, category, description, and ESI value.

Views

Accumulated damage contains the accumulated damage and environmental-effects map. Damage/Env Effect by Earthquake(s) provides an earthquake selector; the event list can be filtered by event Confidence, and selecting an earthquake displays all linked damage and environmental-effect records in separate toggleable layers, with per-event statistics by record confidence and severity.

Scope

The symbols represent documented historical effects at reported sites. They do not necessarily represent earthquake epicentres or instrumental ground-motion measurements.
