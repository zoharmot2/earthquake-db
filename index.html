About the data

The map loads the repository CSV files directly in the browser. Site records are joined only through Sites_GlobalID → GlobalID. Event records are joined only through Event_Id → Id.

When an event identifier has no corresponding record in the reliable event catalogue, the effect record remains visible and is labelled No linked event record. No fallback matching by site name, date, magnitude, or coordinates is performed.

Each marker represents one site within one thematic layer. Its popup aggregates all matching records for that site.
