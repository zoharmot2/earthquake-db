# v1.1 Manual Testing Checklist

Do not mark v1.1 as stable until this checklist has been completed on the
published GitHub Pages site.

## Deployment

- [ ] GitHub Pages deployment completed successfully.
- [ ] The published URL opens without a 404.
- [ ] No failed JavaScript or CSV requests appear in Developer Tools.
- [ ] No errors appear in the browser console.
- [ ] A hard refresh loads the current repository data.

## Initial map state

- [ ] OpenStreetMap is the default base map.
- [ ] The opening extent covers Eilat through southern Turkey.
- [ ] Both thematic layers are initially visible.
- [ ] The thematic legend appears on the left.
- [ ] Summary counts finish loading.

## Base maps

- [ ] OpenStreetMap loads.
- [ ] Light map loads.
- [ ] Satellite imagery loads.
- [ ] Attribution remains visible for each base map.

## Earthquake Damage

- [ ] Damage markers are circles.
- [ ] Circle size follows `Damage_Val`.
- [ ] The legend lists Felt, Light, Moderate, Heavy, and Severe.
- [ ] Turning off the layer removes its markers and legend section.
- [ ] Turning the layer back on restores them.

## Environmental Effects

- [ ] Environmental markers are squares.
- [ ] Square color follows `Env_Eff`.
- [ ] Square size follows `ESI_Val`.
- [ ] Multi-type sites display segmented squares.
- [ ] The legend lists the visible environmental-effect colors.
- [ ] Turning off the layer removes its markers and legend section.

## Search and filters

- [ ] Site search returns relevant partial-name matches.
- [ ] Selecting a result zooms to the correct site.
- [ ] All records filter works.
- [ ] Linked event records only works.
- [ ] No linked event record only works.
- [ ] Reset restores the initial view, layers, and filters.

## Popups

- [ ] Site name is visible.
- [ ] Layer name is visible.
- [ ] Record count is correct.
- [ ] Records are chronologically ordered.
- [ ] Record accordions open and close.
- [ ] Long descriptions are readable.
- [ ] Linked event information displays correctly.
- [ ] Unlinked records display `No linked event record`.
- [ ] Event ID remains visible for unlinked records.
- [ ] No popup contains raw `undefined`, `null`, or `[object Object]`.

## Responsive layout

- [ ] Desktop Chrome.
- [ ] Desktop Firefox.
- [ ] Desktop Edge.
- [ ] Narrow browser window.
- [ ] Mobile portrait.
- [ ] Mobile landscape.
- [ ] Map controls remain usable by touch.
- [ ] Popups remain within the viewport.

## Data integrity

- [ ] No site `GlobalID` duplicates.
- [ ] Every damage record links to a site.
- [ ] Every environmental record links to a site.
- [ ] Expected unlinked event counts match the QA report.
