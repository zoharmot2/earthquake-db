# Stage 3.2 — Map View and Legend Revision

## Changes

1. The opening extent is focused from Eilat to southern Turkey and uses a
   wider, smaller-scale regional view.
2. OpenStreetMap is the default base map.
3. Environmental-effect markers are squares rather than circles.
4. The dynamic thematic legend is positioned on the left side of the map.
5. The environmental legend is shown directly under the Environmental Effects
   layer heading and lists only `Env_Eff` color categories.
6. `ESI_Val` continues to control environmental-symbol size, but a separate
   environmental-severity legend is intentionally omitted. The ESI value
   remains available in tooltips and popups.
