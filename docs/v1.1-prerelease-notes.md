# v1.1 Pre-release Notes

This package is a review build and is not yet the stable v1.1 release.

## Improvements in this build

- Redesigned popup hierarchy.
- Collapsible records for sites with long histories.
- Clear linked and unlinked event status.
- Improved field labels and missing-value handling.
- Expanded About content.
- Full README.
- Map data dictionary.
- Automated QA report.
- Manual cross-browser and mobile testing checklist.

## Known data issue

The map intentionally includes 151 damage records and 4 environmental-effect
records that are not linked to the reliable event catalogue.
